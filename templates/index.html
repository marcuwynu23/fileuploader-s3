Upload Single File

POST
/api/fileuploader/upload

Upload a single file to a specified folder.

Request

curl -X POST {base_url}/api/fileuploader/upload \
  -F "folder=documents" \
  -F "file=@example.pdf"

Response

{
  "message": "File successfully uploaded",
  "url": "{base_url}/uploads/documents/example.pdf",
  "filename": "example.pdf",
  "folder": "documents",
  "size": 1024000,
  "mime_type": "application/pdf"
}
