# Release Notes - v0.0.1-beta

**Release Date:** May 7, 2026

Welcome to the first beta release of Bucket FileUploader! This version establishes the foundation of the project with core functionality and improved development workflow.

---

## What's New

### Project Setup
- **UV Package Manager** - Migrated from Poetry to UV for faster Python package management
- **Modular Codebase** - Reorganized code into separate modules for better maintainability
- **Test Suite** - Added initial test cases to ensure code quality

### Development Improvements
- Cleaner project structure with separated concerns
- Faster dependency resolution and installation with UV
- Foundation for future feature development

---

## Known Limitations

This is an early beta release. Some features are still in development:
- Limited observability capabilities
- Basic Docker support only
- Documentation is minimal
